Case Study

Extensão de DC on-prem para SWX Cloud com VMware HCX

Varejo com 300 lojas. Estendemos cluster vSphere para nuvem soberana, migração vMotion L2, DR automatizado, RPO < 15 min, RTO < 1h.

VMwareHCXDRHíbrida

O Desafio

Rede varejista com 300 lojas, DC on-prem saturado (compute, storage, rede), necessidade de DR real (não apenas backup), soberania de dados (LGPD), e expansão para novas regiões sem CAPEX de novo data center.

Restrições

  • VMware lock-in: vSphere 7, vSAN, NSX-T, centenas de VMs, scripts, integrações
  • L2 adjacency: Aplicações legadas dependem de broadcast, IP fixo, VLANs estendidas
  • Janela de migração: Finais de semana apenas, lojas não podem parar
  • DR real: RPO < 15 min, RTO < 1h, teste trimestral obrigatório
  • Soberania: Dados de clientes (LGPD) devem permanecer no Brasil

A Solução: VMware HCX + SWX Cloud

Extensão nativa do SDDC on-prem para cloud soberana brasileira — mesma API, mesma operação, mobilidade L2 real.

Arquitetura Híbrida

  • HCX Manager on-prem + HCX Cloud Service na SWX
  • Service Mesh HCX: WAN optimization, deduplicação, compressão
  • L2 Extension: VLANs estendidas via VXLAN sobre IPsec
  • Network Extension: HCX NE appliance, mobilidade de IP/VM
  • Compute Profile SWX: vSphere 8, vSAN 8, NSX-T gerenciado

Migração vMotion L2 (Zero Downtime)

  • Ondas por loja/região: 50 VMs/onda, validação pós-migração
  • vMotion cross-site: memória + storage, IP/MAC preservados
  • Bulk Migration: cold migration para workloads não-críticos
  • Replication Assisted vMotion: pre-sync storage, cutover rápido
  • Rollback automático: HCX watchdog, timeout configurável

Disaster Recovery Automatizado

  • HCX DR: replicação contínua (RPO < 15 min), failover 1-click
  • Runbooks: failover por site, por aplicação, por prioridade
  • Testes trimestrais: non-disruptive DR test (network isolation)
  • RTO < 1h validado: 45 min média em testes
  • Failback automatizado: reverse replication, re-IP se necessário

Expansão & Otimização

  • Novas lojas: deploy direto na SWX (template + HCX L2 extension)
  • Burst capacity: Black Friday, datas comemorativas — scale-out automático
  • Cost optimization: VMs dev/test só na cloud, desligadas fora de horário
  • Backup: Veeam + SWX Object Storage (S3-compat), imutabilidade
