1. Chunking — A Base de Tudo

EstratégiaTamanhoOverlapIdeal para
Fixed-size512-1024 tokens10-20%Docs uniformes, FAQs
Semantic (spaCy/LangChain)VariávelN/ATextos longos, capítulos, seções
Recursive (markdown/HTML aware)512 tokens50 tokensDocs técnicos, código, markdown
Agentic (LLM-driven)AdaptativoN/AContratos, legislação, alto valor

Nossa escolha padrão: RecursiveCharacterTextSplitter (chunk_size=800, chunk_overlap=100) + metadata (source, page, section, doc_id).

4. Rerank — Vale a Pena?

  • Cross-encoder (Cohere Rerank, bge-reranker, Jina Reranker): reordena top-50 → top-5. Ganho de recall @5: +15-30%.
  • Latência extra: 50-150ms. Use apenas se precisão > velocidade (jurídico, médico, compliance).
  • Para chat/atendimento: rerank + citação de fonte obrigatória.
