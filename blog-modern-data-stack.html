Modern Data Stack: da ingestão ao BI governado em 6 camadas

Airbyte/Fivetran → dbt → Snowflake/BigQuery → Power BI/Looker → DataHub → Monte Carlo. Padrões, armadilhas e custo por maturidade.

13 min de leitura20/10/2026IT Cloud Solutions

As 6 Camadas

1. Ingestão (ELT)

Fivetran (managed, 300+ connectors, CDC) ou Airbyte (open-source, self-hosted, custom connectors). CDC nativo para bancos, API pagination, schema evolution.

2. Transformação (dbt)

SQL-first, modular, testável, versionado. Models (staging → intermediate → marts), tests (unique, not_null, relationships), docs auto-geradas, CI/CD (dbt Cloud / GitHub Actions).

3. Warehouse / Lakehouse

Snowflake (multi-cloud, zero-copy cloning, time travel), BigQuery (serverless, slots, BI Engine, ML nativo), Redshift (RA3, Spectrum, datasharing), Databricks/Synapse (Delta Lake, Spark).

4. BI & Analytics

Power BI (RLS, paginated reports, XMLA, deployment pipelines), Looker (LookML, semantic layer, embedded), Tableau (Hyper, extensions), Metabase (open-source, embedding).

5. Catálogo & Governança (DataHub)

Metadados ativos (lineage coluna-a-coluna, ownership, tags, glossário), PII detection, search & discovery, API GraphQL, integração dbt/Snowflake/BigQuery/Power BI.

6. Observabilidade de Dados (Monte Carlo)

Freshness, volume, schema, distribution, lineage alerts. Anomalias via ML, root cause analysis, SLA de dados, integração PagerDuty/Slack/Teams.
