VMware: SDDC, Híbrida, Kubernetes e Mobilidade de Cargas

Muitas cargas ainda rodam (e vão rodar) on-premise. Somos especialistas em vSphere, vSAN, NSX, Tanzu, HCX — e na extensão transparente para nuvens públicas (VMware Cloud on AWS, Azure VMware Solution, OCI CVS, Google Cloud VMware Engine, SWX).

Por que VMware com a IT Cloud Solutions

Conhecemos o stack VMware de ponta a ponta: do hardware (VxRail, HPE, Dell, Lenovo) à nuvem, passando por Kubernetes, rede, segurança e DR.

SDDC Completo (vSphere, vSAN, NSX)

  • vSphere 8: lifecycle manager, Tanzu Kubernetes Grid, identity federation
  • vSAN 8: ESA (Express Storage Architecture), compression, dedup, stretch cluster
  • NSX-T: microsegmentação, distributed firewall, load balancer, VPN, NAT
  • Aria Operations/Automation: capacity, cost, compliance, self-service catalog

Híbrida & Mobilidade (HCX)

  • HCX: L2 extension, vMotion cross-cloud, bulk migration, replication assisted
  • VMware Cloud on AWS (VMC): SDDC nativo, ENI, Direct Connect, HCX built-in
  • Azure VMware Solution (AVS): private cloud, ExpressRoute, HCX, Azure services
  • OCI CVS / Google Cloud VMware Engine / SWX: mesma experiência, providers diferentes

Kubernetes Moderno (Tanzu)

  • Tanzu Kubernetes Grid (TKG): clusters conformes, CNI/CNI, CSI, add-ons
  • Tanzu Mission Control: gestão multi-cluster (on-prem + cloud), policies, inspection
  • Tanzu Service Mesh: Istio gerenciado, mTLS, observabilidade, traffic management
  • Harbor Registry, Tanzu Application Platform (TAP): supply chain, developer portal

Segurança & Compliance (NSX, Carbon Black)

  • NSX Distributed Firewall: microsegmentação L2-L7, IDS/IPS, context-aware
  • Carbon Black Cloud: EDR/XDR nativo no endpoint, behavioral, reputation
  • vSphere Trust Authority: attestation, encrypted vMotion, TPM 2.0, TEE
  • Compliance: CIS, PCI, STIG — Aria Compliance (antigo vRealize Compliance)

Infraestrutura & Hardware (VCF, VxRail)

  • VMware Cloud Foundation (VCF): SDDC full-stack, lifecycle automatizado (SDDC Manager)
  • VxRail: HCI Dell/EMC, deploy 30 min, LCM unificado, stretch cluster nativo
  • HPE SimpliVity, Lenovo ThinkAgile, Fujitsu Primeflex — parcerias certificadas
  • Licenciamento: subscription (per core), Cloud Universal, term licenses

DR & Backup (Site Recovery, Veeam, Zerto)

  • Site Recovery Manager (SRM): planos, test non-disruptive, failover orchestrado
  • Veeam: backup/replication vSphere, vSAN, NSX, Kubernetes, cloud, immutability
  • Zerto: CDP (continuous data protection), journal-based, RPO segundos
  • Rubrik, Commvault, Dell PowerProtect — integração nativa vSphere/vSAN
