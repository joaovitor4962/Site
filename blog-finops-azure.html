FinOps na prática: como reduzimos 32% da fatura cloud de um cliente enterprise

Tagging obrigatório, rightsizing automatizado, Savings Plans, compra de RIs e showback por squad. O passo a passo que aplicamos em 90 dias.

12 min de leitura15/10/2026IT Cloud Solutions

O Desafio

Indústria automotiva, 2.500 recursos ativos, 12 subscriptions Azure, fatura mensal superior a R$ 1,2M. Falta de visibilidade: 68% dos recursos sem tags, instâncias oversized, zero governança de compra reservada.

A Abordagem

1. Fundação: Tagging Obrigatório

Implementamos Azure Policy com efeito deny para criação de recursos sem tags Environment, Owner, CostCenter, Application, Project. Em 30 dias: cobertura de tags saltou de 32% para 99.7%.

2. Rightsizing Automatizado

Azure Advisor + script custom (Azure Functions + PowerShell) rodando diariamente: identifica VMs com CPU < 10% (P95 7d), memória < 20%, discos não anexados, IPs públicos órfãos. Aprovação via ServiceNow; execução em janela de manutenção. Resultado: 340 VMs redimensionadas, economia imediata de 18%.

3. Savings Plans & Reserved Instances

Análise de uso estável (baseline 90d) → compra de Compute Savings Plans 3y All Upfront para workloads previsíveis (AKS, VMSS, SAP). Para workloads variáveis: Savings Plans 1y No Upfront + Reserved Instances conversíveis (flexibilidade de tamanho/família). Cobertura de commit: 72% do spend compute.

4. Showback por Squad

Cost Management + Power BI Embedded: dashboards por CostCenter/Application. Alertas de anomalia (spike > 20% WoW) no Teams. Squads passam a ter ownership financeiro — cultura FinOps real.

Resultados (90 dias)

32%redução total da fatura
R$ 460k/mêseconomia absoluta
72%cobertura commit

Lições Aprendidas

  • Tagging é pré-requisito — sem isso, FinOps é "chute"
  • Automação + aprovação humana = velocidade com segurança
  • Showback só funciona se houver consequência (bonus/OKR atrelado)
  • Revisão mensal de RIs/SPs evita "zombie commitments"
Dica: Comece pelo Quick Wins (discos órfãos, IPs públicos, snapshots antigos) — costuma pagar o projeto no primeiro mês.
