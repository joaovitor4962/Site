Case Study

Refatoração para serverless na AWS: custos 60% menores, escala automática

EdTech, monólito em EC2. Migramos para API Gateway + Lambda + DynamoDB + EventBridge + Step Functions. Cold start otimizado, observabilidade nativa.

AWSServerlessLambdaStartup

O Desafio

Startup EdTech com plataforma de cursos online, monólito Node.js/Express em EC2 Auto Scaling Group. Picos de acesso (lançamentos, provas) causavam scale-out lento, cold starts de instância, custos elevados 24/7. Time pequeno, sem expertise DevOps profunda.

Dores

  • Scale-out lento: EC2 launch 3-5 min, usuários viam erro 5xx no pico
  • Custo ocioso: ASG min=3 para buffer, 70% CPU idle fora de pico
  • Deploy arriscado: Rolling update, health check frágil, rollback manual
  • Observabilidade limitada: CloudWatch básico, sem tracing distribuído
  • Time enxuto: 3 devs, nenhum DevOps dedicado

A Solução: Serverless Native AWS

Refatoração incremental (Strangler Fig) para arquitetura event-driven, fully managed, pay-per-use.

API Gateway + Lambda (Strangler Fig)

  • API Gateway REST: custom domain, WAF, throttling, caching, usage plans
    • Lambda (Node.js 20): funções por domínio (auth, courses, payments, users) Lambda Power Tuning: right-sizing memory/CPU automático (step function) Provisioned Concurrency: 10 instâncias quentes para endpoints críticos (login, checkout)

DynamoDB (Single Table Design)

  • Tabela única: PK/SK compostos, GSIs para acessos por usuário, curso, categoria
    • On-demand billing: escala automática, zero admin, PITR 35 dias TTL para sessões, cache, tokens expirados Streams → Lambda → ElasticSearch (OpenSearch) para search full-text

EventBridge + Step Functions (Orquestração)

  • Event Bridge: bus custom, rules por evento (user.enrolled, payment.confirmed, course.completed)
    • Step Functions: workflows matrícula, emissão certificado, notificações, retry/backoff nativo Express Workflows: alta throughput, baixa latência (síncronos) Dead Letter Queues (SQS) + reprocessamento automático

Observabilidade & CI/CD

  • X-Ray: tracing end-to-end (API Gateway → Lambda → DynamoDB → Step Functions)
    • CloudWatch Insights: logs estruturados JSON, queries ad-hoc, métricas custom SAM/Serverless Framework: IaC, deploy canary (10% → 50% → 100%), rollback automático GitHub Actions: test, lint, build, deploy, smoke test, notify Slack

Segurança & Compliance

  • Cognito: user pools, MFA, social login, custom auth challenge (magic link)
    • WAF: rate limiting, IP reputation, SQLi/XSS managed rules, bot control Secrets Manager: DB creds, JWT keys, 3rd party API keys — rotation automática LGPD: consentimento, DSR automation, data retention policies

Otimização de Custo Contínua

  • Compute Savings Plans: 1 ano, commit baseado em uso histórico Lambda
    • DynamoDB: on-demand → provisioned com autoscaling quando padrão previsível API Gateway: caching 300s para catálogo cursos, reduce Lambda invocations 40% CloudWatch: log retention 30d, metric filters só o necessário, dashboards compartilhados

Resultados Mensuráveis

60%menos custo mensal
10xescala pico (Black Friday)
<50msp95 latency (warm)
0ops infra (managed)
Depoimento do CTO: "Serverless nos libertou de gerenciar servidor. No lançamento do curso do ano, tivemos 50k usuários simultâneos — zero incidente, custo previsível. O time foca 100% no produto."
