Case Study

Modern Data Platform: do Excel descentralizado ao Data Lake governado

Manufatura, 50+ planilhas, 15 fontes. Airbyte → dbt → Synapse → Power BI. Catálogo DataHub, quality Great Expectations, lineage automático.

AzureSynapsePower BIIndústria

O Desafio

Indústria manufatureira com 5 fábricas, 50+ planilhas Excel descentralizadas, 15 fontes de dados (ERP, MES, qualidade, manutenção, logística), versão da verdade inexistente, relatórios manuais semanais levavam dias, decisões baseadas em dados desatualizados.

Dores Principais

  • Excel hell: 50+ arquivos, versões conflitantes, fórmulas quebradas, sem auditoria
  • Silos de dados: ERP, MES, LIMS, CMMS, WMS não conversam
  • Lead time relatórios: 3-5 dias para fechar relatório gerencial semanal
  • Qualidade duvidosa: Nenhum teste de dado, anomalias descobertas tardiamente
  • Governança zero: Sem catálogo, sem lineage, sem ownership, LGPD risk

A Solução: Modern Data Stack no Azure

Arquitetura em camadas: ingestão → transformação → armazenamento → consumo → governança.

1. Ingestão (Airbyte + Custom)

  • 15 conectores: SAP (OData), MES (REST), LIMS (DB), CMMS (CSV/SFTP), etc.
    • CDC para ERP: captura mudanças near real-time Raw zone (Data Lake Gen2): parquet partitionado por data/fonte Orquestração: Airflow (Azure Data Factory) com retry, alerting, SLA

2. Transformação (dbt + SQL)

  • Staging → Intermediate → Marts (dimensional Kimball)
    • Modelos versionados no Git, CI/CD (GitHub Actions + dbt Cloud) Testes: not_null, unique, relationships, accepted_values, custom Documentação auto-gerada (dbt docs), lineage column-level

3. Armazenamento & Serving (Synapse)

  • Dedicated SQL Pool (DW1000c → elastic) para marts
    • Serverless SQL Pool para ad-hoc sobre raw zone Spark Pools para feature engineering / ML futuro Workspace RBAC: read-only analysts, read-write engineers

4. Consumo (Power BI Governado)

  • 120+ dashboards: executivo, produção, qualidade, manutenção, supply
    • Row-level security: cada gestor vê só sua planta/área Deployment pipelines: dev → test → prod, approval gates Paginated reports para relatórios regulatórios (PDF/Excel agendados)

5. Governança (DataHub + Great Expectations)

  • DataHub: catálogo, lineage end-to-end, ownership, glossário negócio
    • Great Expectations: suites por camada, validação no pipeline, alertas Slack Data contracts: schema evolution, breaking change detection PII tagging automático, acesso controlado, LGPD compliance

6. People & Process

  • Data stewards por domínio (produção, qualidade, supply, etc.)
    • Analytics engineering squad: 3 engenheiros + 1 lead Treinamento: SQL, dbt, Power BI, data literacy para 50+ usuários SLA de dado: freshness < 4h, accuracy > 99.5%
